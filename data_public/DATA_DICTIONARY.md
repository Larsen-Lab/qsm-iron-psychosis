# De-identified analysis dataset

`qsm_iron_psychosis_analysis_data.csv` — participant-level data for the variables used in the
analyses reported in the manuscript. One row per imaging session; 263 sessions from 183
participants (PS n = 127; TD n = 56).

Generated by `curate_public_data.R` from the source study data. Participant and session IDs were
replaced with fresh, shuffled identifiers with no link to the original study records; date-like
fields, demographics not used in analyses (race, ethnicity, education, handedness, gender
identity), internal QC ratings, and raw neurocognitive subtest scores were removed.

## Columns

| Column | Description |
|---|---|
| `participant_id` | De-identified participant ID (`sub-0001` …), assigned in shuffled order |
| `session` | Within-participant visit index (`ses-01` …), ordered by age |
| `age` | Age in years at the imaging session |
| `sex` | Sex (Male / Female) |
| `study.group` | Clinical group: PS = psychosis spectrum, TD = typically developing |
| `dataset` | Source cohort: EF or MOTIVE |
| `Ca`, `Pu`, `NAC` | Striatal susceptibility (ppm): caudate, putamen, nucleus accumbens |
| `GPe`, `GPi`, `VeP`, `Pallidum_Total` | Pallidal susceptibility (ppm); `Pallidum_Total` = voxel-weighted composite |
| `SNc`, `SNr`, `PBP`, `VTA`, `RN`, `SN_Total`, `VTA_Total` | Midbrain susceptibility (ppm); `SN_Total`/`VTA_Total` = composites |
| `STH` | Subthalamic nucleus susceptibility (ppm) |
| `Subcortex_Total` | Whole-subcortex composite susceptibility (ppm), voxel-count weighted |
| `Overall_Efficiency` | Overall cognitive efficiency factor (Penn CNB) |
| `SocialCog_Efficiency`, `Memory_Efficiency`, `Executive_Efficiency`, `Complex_Efficiency` | Domain cognitive efficiency scores |
| `med_any_psych` | Any psychotropic medication use across visits (0/1) |
| `med_stimulant`, `med_antidepressant`, `med_any_ap`, `med_mood_stab`, `med_anxiolytic` | Medication class flags (0/1): stimulant, antidepressant, antipsychotic, mood stabilizer, anxiolytic |
| `iron_supplement` | Oral iron supplement use (0/1) |

## Notes
- Susceptibility is in parts per million (ppm) from quantitative susceptibility mapping (QSM).
- Medication flags are subject-level ("any use across visits") and repeat across a participant's sessions.
- The full manuscript pipeline (`QSM_Analysis_Submission.Rmd`) also performs raw image processing and
  QC that require the source imaging data; this CSV provides the analysis-ready variables sufficient
  to reproduce the reported statistical models.
